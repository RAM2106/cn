Computer Networks Lab - Short C Programs
=========================================
Files are named by experiment and topic.

Compile a program with GCC:
    gcc exp10_dijkstra.c -o exp10
Run on Windows CMD:
    exp10.exe

Notes:
- These are short educational simulations intended for lab practice.
- Experiment 3 is a simplified 8-bit checksum.
- Experiment 4 generates Hamming (7,4) code; it does not decode/correct an entered error.
- Experiments 6-8 simulate acknowledgement behaviour; they do not use actual sockets.
- Experiment 11 calculates shortest route costs using iterative distance updates.
- Check your lab manual's required input/output conventions with your faculty.
